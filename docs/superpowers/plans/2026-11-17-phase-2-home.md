# Phase 2: Home Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the real Home page from the v11 mockup. It covers:
- header, intro and photo
- the four project blocks with stack, stats, proof links and screenshot
- the capabilities strip
- the contact section (markup only)
- the footer

`/projects` and `/contact` work as clean section URLs. Phase 1's carry-forward items for Phase 2 are closed.

**Architecture:**
- **Content:** typed data in `app/data/` (projects and site), with one pure function `proofItems()` deciding the proof links.
- **Components:** small single-purpose Vue components with scoped CSS ported from v11. Shared primitives (`.btn`, `.actions`, `.status`) go in one global stylesheet.
- **Layout:** a default layout holds the skip link, header, `<main>` and footer.
- **Section URLs:** Home is aliased to `/projects` and `/contact` (`key: 'home'`). A router `scrollBehavior` and a same-route click handler scroll to the section and move focus to it.

**Tech Stack:** Nuxt 4.6 (static generate), @nuxt/image 2 (`NuxtPicture`/`NuxtImg`), Vitest 5 + @nuxt/test-utils 4 (`mountSuspended`), Playwright + @axe-core/playwright, plain CSS.

**Spec:** `docs/superpowers/specs/2026-11-17-portfolio-rewrite-design.md`. Phase 2 is in "Phased development plan". Also read the content model, design system, IA/URLs and "Email address exposure" sections.

**Carry-forward:** `docs/superpowers/plans/2026-11-17-phase-1-carry-forward.md`. Its "Facts learned" section and its Phase 2 list are requirements for this plan.

## Global Constraints

- **Node:** run every `node`/`npm`/`npx` command as `fnm exec --using=24 -- <command>`.
- **Git:** never `git commit`, `git push`, `git add`, `git stash`, or open a PR. The controller stages approved work. The phase ends with one proposed commit that needs James's explicit OK.
- **Copy:**
  - Every visible string comes from v11 verbatim, except for the changes listed in this plan.
  - American English, no em dashes anywhere (comments included), no "→" in UI text, no middle-dot meta strings, sentence case.
- **Design:**
  - Use the v11 tokens already in `app/assets/css/tokens.css` by name (`--accent`, `--soft`, `--tap`, `--wrap: 1180px`, `--gutter`, `--shadow-frame`, and so on).
  - Plain CSS: no Tailwind, no UI library, no new colors or sizes outside the tokens.
- **Launch state (James's decision):** only Case study is enabled. Video, Code and Live demo are disabled on all four projects. No live demo URLs exist.
- **Email:** the email address never appears in generated HTML. In Phase 2, every Email link renders `href="/contact"` (Phase 4 adds the `mailto:` switch).
- **Screenshots:**
  - Never cropped: `width: 100%; height: auto`.
  - Served as AVIF and WebP through `NuxtPicture`, with every `sizes` entry prefixed (carry-forward fact).
  - The portrait is the only image allowed `object-fit: cover`.
- **Scope:** don't touch `.github/`, `README.md`, `DESIGN.md`, `docs/superpowers/specs/`, the case study page content (Phase 3), or the contact form behavior (Phase 4).
- **Responsive:** no horizontal page overflow from 360 to 1440. Touch targets are at least `var(--tap)` (44px).

## Review Focus

1. **Clicking a nav item for the page you're already on** should still scroll to that section. For example: load `/projects`, scroll to the bottom, click "Projects". Vue Router ignores same-path navigation. Test: Task 6, `same-route nav click still scrolls`.
2. **Back button after nav clicks:** going from `/` to `/contact` and back returns to `/` at the previous scroll position. Test: Task 6, `back restores previous position`.
3. **Focus after a nav jump:** keyboard users land in the target section, not stranded in the header. Test: Task 6, `keyboard nav moves focus to the section heading`.
4. **Disabled proof items must read as disabled links to screen readers.** A bare `<span aria-disabled>` isn't announced as disabled. Test: Task 4, `disabled items are role=link aria-disabled and unfocusable`.
5. **Long tokens at 360px:** "drf-spectacular (OpenAPI)", long stat labels and the frame address must not cause horizontal scroll. Test: Task 5, `no horizontal overflow` at 360.
